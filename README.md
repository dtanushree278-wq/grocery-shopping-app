# FreshCart — Online Grocery Shopping App

A responsive front-end grocery shopping project made with **HTML, CSS and Vanilla JavaScript**.

## Features
- Responsive home page and grocery product catalogue
- Product categories and live search
- Add products to cart
- Increase/decrease quantity and remove items
- Automatic subtotal, delivery fee and total calculation
- Checkout form with basic browser validation
- Demo order placement and order history saved in browser localStorage
- Cart remains saved after refreshing the page

## How to run
1. Extract `Online_Grocery_Shopping_App.zip`.
2. Open the `online_grocery_shopping_app` folder.
3. Double-click `index.html` or open it with Chrome / Microsoft Edge.
4. Search products, add items to cart and test the checkout.

No installation, server or database is required.

## Project structure
- `index.html` — page structure and checkout form
- `style.css` — layout, colours, responsive design
- `script.js` — product data, cart, calculations and demo order logic

## Important note
This is a client-side academic demo. It does not connect to a real payment gateway, delivery service, authentication system or online database. Cart and demo orders are stored only in the current browser using localStorage.

## Suggested project details
**Project title:** Online Grocery Shopping System (FreshCart)  
**Technology:** HTML5, CSS3, JavaScript, Browser localStorage
